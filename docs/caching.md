`cache_rework` effort (a `CachedResponse`/`serialize_cached_response`-based
design that no longer exists in `src/`). It is retired and kept only so
historical links from `docs/plans/cache_rework/**` and
`docs/plans/ttl_remaining/**` continue to resolve.

For current, accurate caching behavior, see
[docs/knowledge/resolver/caching/](knowledge/resolver/caching/index.md).
